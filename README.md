## What I am working on


- **Smart-RMS** – a recruitment management system built by a four-person team: ASP.NET Core, Dapper, MySQL, Redis and a React front end. My work covers private CV storage, a durable email outbox for candidate magic links, candidate sessions, a retention purge, and the security audit tests around them.
- **Synara** – my graduation project: an AI decision-intelligence platform for procurement (Next.js, FastAPI, PostgreSQL).
- Training at **ProGineer Technologies** on C#, OOP, LINQ, EF Core, Dapper and SQL.


## How I work


- One ticket, one branch, small single-purpose commits, and pull requests that pass CI before merge.
- Migrations are ordered and never rewritten once merged; upgrades and fresh installs are both verified on a real database.
- Anything that touches security (sessions, tokens, files) gets tests before it gets merged.
